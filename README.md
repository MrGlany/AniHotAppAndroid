## ✨ Всё для просмотра аниме

| | Возможность |
|:---:|---|
| 🎬 | **Каталог и поиск.** Находи аниме, изучай описание, жанры, рейтинги и связанные тайтлы. |
| ▶️ | **Удобный плеер.** Выбирай озвучку, серии и источник видео; продолжай с места остановки. |
| 💗 | **Личная библиотека.** Избранное, собственные категории, история просмотров и коллекции. |
| 📥 | **Загрузки.** Сохраняй доступные серии на устройство и управляй загрузками. |
| 👥 | **Совместный просмотр.** Смотри серии в комнатах вместе с друзьями, общайся в чате и голосом. |
| 💬 | **Сообщество.** Профили, друзья, сообщения, комментарии, оценки и рецензии. |
| 🔔 | **Уведомления.** Узнавай о событиях аккаунта и новых активностях. |
| ✨ | **Дополнительные возможности.** Достижения, оформление профиля и импорт библиотеки из других сервисов. |

### Плеер, которому уделили внимание

- **DirectMPV** — встроенный плеер для просмотра аниме.
- Выбор озвучки и серии, управление воспроизведением и сохранение прогресса.
- **Anime4K** — дополнительная обработка изображения для поддерживаемых устройств.
- Мини-плеер и режим «картинка в картинке» там, где это поддерживается устройством.
- Работа с потоковыми источниками, включая HLS, если формат предоставляет выбранный источник.

> [!NOTE]
> Доступность конкретного видео, озвучки, загрузки и некоторых функций зависит от источника, сети, версии приложения и устройства.

## 📲 Скачать и установить

<div align="center">

### [⬇ Перейти к последнему релизу Android](https://github.com/MrGlany/AniHotAppAndroid/releases/latest)

**Формат:** `APK` · **Платформа:** Android

</div>

1. Открой раздел **Releases** по ссылке выше.
2. В последнем релизе раскрой **Assets** и скачай файл с расширением `.apk`.
3. Открой скачанный APK на телефоне.
4. Если Android попросит разрешение, предоставь установку приложений из этого источника, затем заверши установку.

**Обновление:** скачай APK новой версии из [Releases](https://github.com/MrGlany/AniHotAppAndroid/releases) или воспользуйся механизмом обновления в приложении, если он доступен.

> [!IMPORTANT]
> Скачивай установочные файлы из официальных источников. Если Android показывает системное предупреждение при установке APK вне магазина, проверь адрес скачивания перед продолжением.

## ❔ Частые вопросы

**Нужен ли Google Play?**  
Нет. APK можно установить вручную из раздела релизов.

**Можно ли установить ПК-версию?**  
Да, для Windows и Linux существует [отдельный репозиторий AniHot App PC](https://github.com/MrGlany/AniHotAppPC).

**Где посмотреть изменения версий?**  
В [истории релизов Android](https://github.com/MrGlany/AniHotAppAndroid/releases) — у каждой опубликованной версии есть описание обновления.

**Где исходный код?**  
Этот репозиторий предназначен для распространения Android-сборок и файлов обновления. Он не является публичным репозиторием исходного кода.
